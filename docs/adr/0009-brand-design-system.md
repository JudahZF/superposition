# ADR 0009: Brand design system source of truth

- **Status:** Accepted (Phase 0 target)
- **Date:** 2026-07-13

## Context

A supplied raster brand board establishes a visual direction but is not a provenance-complete asset package or implementation system.

## Decision

Use the documented palette, type direction, gradients, and voice as planning tokens only. Keep `/Users/judahfuller/Code/quanta/brandpack.png` as the recorded reference path; do not copy or publish marks/assets until source files and rights are approved. Product UI will use semantic tokens and accessibility review rather than raw colors alone.

## Consequences

The design direction stays consistent without creating false ownership claims. Public release remains blocked on vector assets, licenses/assignments, font and imagery rights, trademark approval, an asset manifest, and final contrast review. See [brand assets](../brand-assets.md).
